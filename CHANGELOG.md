# Changelog

## [Unreleased]

### Рефакторинг

- FSM игрока упрощена до плоской: убраны иерархические `ExploringState`/`CombatState`, `ISubState` и HFSM (`PlayerHFSM.cs`).
- `StateMachine` больше не зависит от игрока; состояния сами переключаются через `ChangeState`; добавлена защита от повторного входа в то же состояние.
- Починено «залипание» диалога: вход по F блокирует движение, выход по Esc (`InteractionState`); Esc больше не открывает книгу во время диалога.
- Взаимодействие: один объект за нажатие (раньше NPC одновременно говорил и открывал меню, а несколько пикапов подбирались одним кликом).
- Переименованы интерфейсы с опечатками: `IDamagable` → `IDamageable`, `ISpeekable` → `ISpeakable`.
- Убран мусорный/отладочный код: спам-принты, мат в заглушках, кнопка-мусор в `FollowMenu`, мёртвые поля в `InputComponent`, закомментированный код.
- `Inventory.AddItem(null)` больше не падает с NullReference.
