# Build-and-Mine
## Описание
BaM - top-down проект Maev dev. Игра, в которой ты играешь за кастомизированного персонажа в отрытом RPG мире.
Твои возможности огромнны, игрок не имеет ограничений сюжета, с самого начала игрок может идти на все 4 стороны и прокачиваться.
Цель игры - выжить в этом суровом мире.

## Планируемые механики

- Прокачка персонажа
- Система навыков
- Исследование открытого мира
- Выживание
- Крафт
- Строительство
- NPC
- Торговля

## Механники, которых не будет

- Искусственного гринда
- Линейного прохождения
- Жесткой привязки к сюжету
- Пошаговой боевой системы

## Архитектурный стиль
Компонентный ООП с легкой расишияемостью. SOLID система. Использование паттернов.
