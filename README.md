# Curiosity
## Описание
Curiosity - проект MaevDev, где ты исследуешь мир совсем чужой тебе. Ты здесь никого не знаешь и никто не знает тебя, но этот мир магии полон загадок, которые тебе предстоит решить... или нет. Ты можешь просто уйти прокачиваться и делать все что душе угодно. История не линейна, ты ее сам строишь.

---

## Ключевые механики

- Прокачка персонажа
- Исследование языков и мира
- Свободный геймплей

## Механики, которых не будет

- Искусственного гринда
- Линейного прохождения
- Жесткой привязки к сюжету
- Пошаговой боевой системы

## Архитектурный стиль

- Компонентный ООП с легкой расширяемостью.
- SOLID система.
- Использование паттернов.


## Roadmap

- Планируется внедрение НПС, где по мере игры будут разблокироваться некоторые слова для взаимодействия с НПС.

## Архитектура

Компонентная архитектура с использованием интерфейсов и композиции. Общая функциональность выносится в компоненты, специализированное поведение реализуется через наследование базовых классов.
