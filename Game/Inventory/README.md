# Инвентарь

Инвентарь хранит предметы в слотах и отображается сеткой `InventoryGrid`. Сетка не принимает решений о перемещении предметов: она передаёт события странице `InventoryPage`, которая знает, какой инвентарь к какой сетке привязан.

## Управление

| Действие | Где | Результат |
| --- | --- | --- |
| Перетаскивание левой кнопкой | любая сетка | обмен слотов внутри инвентаря или перенос между инвентарями |
| Правая кнопка | инвентарь игрока | использовать предмет из слота |
| Правая кнопка | инвентарь лута | перенести весь стак игроку |
| Средняя кнопка | любая сетка | открыть окно выброса с выбором количества |
| `Esc` | окно выброса | отменить выброс |

Инвентарь игрока и второй инвентарь привязываются через `InventoryPage.Bind`:

```csharp
inventoryPage.Bind(player.Inventory, extraInventory, player);
```

`extraInventory` равен `null`, если меню открыто без лута. В этом случае вторая сетка скрывается.

## Лут

Правая кнопка мыши на слоте второго инвентаря переносит предмет игроку:

```csharp
extraInventory.MoveTo(playerInventory, slot.SlotIndex);
```

Если в инвентаре игрока не хватает места, переносится столько предметов, сколько поместилось, остаток остаётся в исходном слоте.

## Выброс

Средняя кнопка мыши открывает `ActionMessage` — модальное окно с ползунком и кнопками «Да»/«нет». Ползунок ограничен количеством предметов в выбранном слоте.

После подтверждения:

1. из конкретного слота удаляется выбранное количество (`Inventory.RemoveFromSlot`);
2. рядом с игроком создаётся `PickUp` с этим предметом и количеством;
3. окно закрывается.

Если игрок закрывает меню или переключает страницу, окно выброса закрывается без изменений. Количество по умолчанию — 1, максимум — размер стака. Значение ползунка округляется до целого.

Выброшенный предмет создаётся из кода, потому что позиция зависит от игрока:

```csharp
var pickup = new PickUp();
pickup.Init(item, count);
player.GetParent().AddChild(pickup);
pickup.GlobalPosition = player.GlobalPosition + new Vector2(24f, 0f);
```

`PickUp` показывает количество при наведении. При подборе предмет добавляется в инвентарь частями: если места хватает не на весь стак, на земле остаётся остаток.

## Модальное окно

`Game/ActionMessage/Scenes/action_message.tscn` содержит ползунок, заголовок и кнопки. Скрипт `ActionMessage` предоставляет:

- `Ask(title, maxCount, initialCount)` — показать окно;
- событие `Confirmed(int count)` — подтверждение;
- событие `Canceled` — отмена.

Окно подключено к `BookMenu` и назначено в `InventoryPage.ActionMessage`. Для другого UI достаточно создать второй экземпляр сцены и назначить его в инспекторе.
